# Projet Building AI - Éléments de l'IA

## Résumé
Ce projet utilise un modèle de machine learning pour prédire le prix des maisons en fonction de la surface, du nombre de pièces et de l'emplacement. 

J'ai entraîné un modèle de régression linéaire sur un jeu de données de 1000 maisons. Les résultats montrent une précision de 85% sur les données de test.

Le modèle permet d'aider les agents immobiliers à estimer rapidement la valeur d'un bien.
